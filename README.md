# 프로젝트 개요

- 2차원 배열 형태의 패턴과 필터를 이용해서 MAC(Multiply Accumulate) 연산을 수행하는 파이썬 콘솔 프로그램입니다.
- 사용자가 직접 입력한 3×3 패턴을 분석할 수 있으며, data.json에 저장된 5×5, 13×13, 25×25 패턴을 각각 분석할 수 있습니다.
- 또한 입력 크기에 따른 MAC 연산 시간을 반복 측정하여 N×N 데이터의 연산량과 실행 시간 변화를 확인할 수 있습니다.

# 실행 환경

- Python 3.8 이상
- 외부 라이브러리 사용 X
- Python 표준 라이브러리 O

> 실행 방법

```bash
python main.py
```

- `data.json` 과 `main.py` 는 동일한 프로젝트 경로에 위치시킵니다.

# MAC 연산

> MAC은 Multiply-Accumulate의 약자로 같은 위치의 값을 곱한 뒤 그 결과를 계속 누적하는 연산입니다.

- score += pattern[row][col] \* filter_matrix[row][col]
- NumPy와 같은 외부 라이브러리를 사용하지 않고 2중 반복문으로 직접 구현하였습니다.
- 하나의 N×N 패턴을 처리할 때 모든 위치를 한 번씩 확인하기 때문에 총 N²개의 위치를 계산합니다.

# 라벨 정규화

> data.json의 외부 표현과 프로그램 내부의 표현을 통일하기 위해 라벨 정규화를 적용하였습니다.

```text
+ -> Cross
cross -> Cross
x -> X
```

- 프로그램 내부에서는 `Cross`와 `X`만 사용합니다.
- 라벨 정규화를 통해 외부 데이터의 표현 방법이 달라도 MAC 판정 결과와 expected 값을 동일한 기준으로 비교할 수 있게 됩니다.

# epsilon 기반 점수 비교

> 부동소수점 값은 컴퓨터 내부에서 항상 정확하게 표현되지 않을 수 있기 때문에 두 점수를 단순히 ==로 비교하지 않았습니다.

- `EPSILON = 1e-9`
- `abs(score_a - score_b) < EPSILON`
- 두 점수의 차이가 epsilon보다 작으면 실질적으로 같은 점수라고 판단하여 UNDECIDED로 처리합니다.
- 그 외에는 더 높은 MAC 점수를 가진 필터를 최종 결과로 선택합니다.

# 시간복잡도

- MAC 연산은 N×N 패턴과 필터의 같은 위치에 있는 값을 모두 확인해야 합니다.
- 행 방향으로 N번 반복하고 각 행에서 열 방향으로 다시 N번 반복하기 때문에 총 N×N번 수행하게 됩니다.
- 이에 따라 MAC 연산의 시간 복잡도는 O(N^2)
- 다만 실제 측정 시간이 정확히 N^2의 비율대로 증가한다고 할 수는 없습니다.
- 실제 실행 시간에는 Python 인터프리터 실행 비용, 운영체제의 스케줄링, CPU 상태, 캐시 등의 환경적인 요소도 영향을 줄 수 있습니다.
