# 미션3 기능 체크리스트

## 1. 기본 실행 / 모드 선택

* [ ] `python main.py`로 정상 실행됨
* [ ] 사용자 입력(3×3) / `data.json` 분석 모드를 선택할 수 있음
* [ ] 외부 라이브러리 없이 Python 표준 라이브러리만 사용함

## 2. 사용자 입력 모드 — 3×3

* [ ] 필터 A, 필터 B, 패턴을 각각 3×3으로 입력받음
* [ ] 행/열 개수 또는 숫자 입력이 잘못되면 재입력할 수 있음
* [ ] 두 필터의 MAC 점수를 계산함
* [ ] epsilon 기준으로 A / B / 판정 불가를 결정함
* [ ] 3×3 MAC 평균 연산 시간을 출력함

## 3. MAC 연산

* [ ] 외부 라이브러리 없이 2중 반복문으로 위치별 `곱셈 + 누적`을 구현함
* [ ] 3×3뿐 아니라 N×N 배열에서도 같은 MAC 함수를 사용할 수 있음
* [ ] 점수 비교 시 `abs(score_a - score_b) < epsilon` 정책을 사용함

## 4. data.json 분석

* [ ] `data.json`에서 filters와 patterns를 정상적으로 읽음
* [ ] `size_5_1`, `size_13_1` 등의 키에서 N을 추출하여 알맞은 필터를 선택함
* [ ] `+ / cross → Cross`, `x → X` 형태로 라벨을 정규화함
* [ ] 패턴과 필터의 N×N 크기가 맞는지 검증함
* [ ] 잘못된 케이스 하나 때문에 프로그램 전체가 종료되지 않음

## 5. JSON 케이스 판정

* [ ] 각 패턴에 대해 Cross/X MAC 점수를 계산함
* [ ] Cross / X / UNDECIDED를 판정함
* [ ] expected와 비교하여 PASS / FAIL을 출력함
* [ ] FAIL인 경우 케이스와 실패 이유를 남김

## 6. 성능 분석

* [ ] 3×3 / 5×5 / 13×13 / 25×25를 측정함
* [ ] 각 크기마다 MAC 연산을 최소 10회 실행하여 평균 시간을 구함
* [ ] I/O 시간이 아니라 MAC 연산 구간을 중심으로 측정함
* [ ] `크기 / 평균 시간(ms) / N² 연산 횟수`를 출력함

## 7. 결과 요약

* [ ] 전체 테스트 수 / PASS / FAIL 수를 출력함
* [ ] 실패 케이스가 있으면 케이스명과 이유를 출력함

## 8. README

* [ ] 실행 방법을 작성함
* [ ] MAC 연산과 epsilon 판정 방식을 간단히 설명함
* [ ] 라벨 정규화를 한 이유를 설명함
* [ ] FAIL이 있다면 원인을 분석하고, 없다면 실패가 0인 이유를 설명함
* [ ] N×N에서 N²번 연산하므로 시간복잡도가 `O(N²)`임을 설명함

## 9. 보너스 — 시간 남으면

* [ ] N을 입력받아 Cross / X 패턴을 자동 생성함
* [ ] 생성기를 N=3으로 고정하지 않고 다양한 N에서 사용할 수 있게 함
* [ ] 생성된 배열을 기존 MAC/성능 분석에 재사용함
* [ ] 여유가 더 있으면 2차원 → 1차원 배열 변환 전후 성능을 비교함
